# Unit Testing

- Design each test to fail for one and only one reason. Align every assertion with that single failure reason.
- Use descriptive test names that identify the scenario and expected behavior.
- Use parameterized tests when cases repeat the same structure with different inputs or expected results.
- Keep tests deterministic, isolated, and focused on observable behavior.
